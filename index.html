Find what makes a text hard to read. Then fix that.

Most reading tools give every page the same treatment. Legible measures the writing first. It tells you the biggest problem in one sentence, and it offers the fix that matches.

Use it on any web page

Drag this button to your bookmarks bar. Then press it on any article, and Legible opens over that page with the diagnosis and the reading view.

Legible this page

How to add it
  1. Show your bookmarks bar. In most browsers that is Ctrl + Shift + B, or Cmd + Shift + B on a Mac.
  2. Drag the “Legible this page” button onto the bar.
  3. Open any page and press the new bookmark. Press it again, or press Escape, to go back.

Select part of a page first and Legible reads only that part.

Firefox will not save a bookmark this large. Use the small version instead. It loads the reader from this site, so a few sites that block outside scripts will open in a new tab.

On a phone bookmarklets are awkward. Copy the text and paste it above.

The large bookmarklet carries all of Legible inside it. It makes no network requests at all.

What Legible does

It diagnoses before it treats

Grade level, sentence length, uncommon words, paragraph length and passive voice are each measured, put on one scale, and ranked. The worst one leads.

Every setting cites its source

Spacing, size, line length and contrast each name the WCAG criterion or the study behind them. Line length and contrast are measured on your screen, not asserted.

It reads aloud and lights the word

Press any word to start from there. Where a voice does not report its position, Legible times it and says so.

It never rewrites you

Long sentences are split at clause boundaries only. Same words, same order, and the original is always one tap away.
